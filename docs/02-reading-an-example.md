# Reading an Example

Every category module follows the same small pattern:

1. A section heading identifies the JavaScript built-in category.
2. A short comment names the method, its return value, and a practical use case.
3. `console.log` displays the result so it can be compared with the source.

For example, `Array.prototype.map()` returns a new array, whereas `Array.prototype.forEach()` returns `undefined`. Reading the output alongside the comment makes that difference visible.
